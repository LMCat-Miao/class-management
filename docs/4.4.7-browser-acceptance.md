# 4.4.7 浏览器人工验收手册

> 依据仓库真实代码整理（`src/` 前端 + `backend/` FastAPI）。  
> **本手册不替代自动化测试**；标注「自动化已验证」的项可作对照，仍建议在浏览器抽查。  
> 验收前请确认：`.env.development` 中 `VITE_USE_MOCK=false`，后端连 **3306 / class_management**。  
> **禁止**删除既有演示数据；临时数据须用可识别前缀（如 `__BA__`）并在用例结束后清理。  
> 演示账号口令以**登录页快捷填充提示**为准，本文不重复书写。

## 3. Admin 操作流程

**账号：** 登录页「管理员」快捷填充。

### 3.1 登录 / 退出

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 打开 http://localhost:5173/login | 登录表单 |
| 2 | 快捷填充管理员并点「登录」 | 成功提示；跳转 `/dashboard` |
| 3 | DevTools → Application → Session Storage | 存在 `access_token` |
| 4 | F5 刷新 | 仍保持登录（守卫调 `/user/info` 并重注路由） |
| 5 | 顶栏「退出登录」 | 清 Token；回 `/login` |

- **自动化：** 登录/JWT/无 refreshToken 等已在后端脚本验证。  
- **浏览器：** 尚待验证刷新与顶栏退出体验。

### 3.2 Dashboard（`/dashboard`）

| 展示项 | 数据性质（以后端 `dashboard_query` 为准） |
|--------|------------------------------------------|
| 课程总数 / 教师总数 / 学生总数 / 累计学习人数 | **真实 MySQL 聚合** |
| 课程分类占比 | **真实**（有课的分类 COUNT） |
| 热门课程排行 | **真实**（按 `learn_count`） |
| 课程平均完成率 | **真实**（课程 `completion_rate` 均值） |
| 「课程与学生趋势」双折线 | **演示硬编码趋势**（非按月真实统计）；UI 有「含演示趋势数据」提示 |

操作：登录后看首页；缩放窗口看卡片/图表是否换行、溢出。

### 3.3 课程管理（`/course`）

| 操作 | 入口/按钮 | 接口 | 预期 |
|------|-----------|------|------|
| 列表 | 侧栏「课程管理」 | `GET /course/list` | 分页表格 |
| 搜索 | 「搜索」 | 同上 + name 等 | 结果收窄 |
| 分类/状态/教师/日期 | 筛选表单 | 同上 | 与条件一致 |
| 重置 | 「重置」 | 重新拉列表 | 条件清空 |
| 分页 | 底部分页器 | page/pageSize | 翻页 |
| 详情 | 「查看」 | `GET /course/{id}` | `/course/:id` |
| 新增 | 「新增课程」 | `POST /course` | 弹窗提交后列表出现 |
| 编辑 | 「编辑」 | `PUT /course/{id}` | 字段更新 |
| 上下架 | 「上架/下架」类按钮（`course:publish`） | `PUT /course/{id}/status` | 状态切换 |
| 删除 | 「删除」 | `DELETE /course/{id}` | 无选课可删；**有选课 → HTTP 409** |

临时数据建议：课程名 `__BA_COURSE_xxx__`，测完删除；有选课的课不要删演示课。

### 3.4 学生管理（`/student`）

| 操作 | 入口 | 接口 | 预期 |
|------|------|------|------|
| 列表/搜索/分页 | 侧栏「学生管理」 | `GET /student/list` | Admin 可见范围内学生 |
| 新增 | 「新增学生」 | `POST /student` | 创建成功 |
| 编辑 | 「编辑」 | `PUT /student/{id}` | 更新成功 |
| 停用/启用 | 「停用」/「启用」 | `PUT /student/{id}/status` | 状态变化 |
| 详情 | 「查看」 | `GET /student/{id}` | 基本信息 +「最近学习」 |
| 选课入口 | 「选课」 | 进详情 | 见下节 |

临时学生：`name=__BA_STU_xxx__`，`studentNo` 唯一；测完删除该学生及相关选课。

### 3.5 选课管理（无独立菜单）

| 操作 | 入口 | 接口 | 预期 |
|------|------|------|------|
| 查看已选 | 详情「选课管理」表 | `GET /enrollment/student/{id}` | 含 courseName、status、enrolledAt |
| 分配 | 「分配课程」→ 选课 →「确定」 | `POST /enrollment` | 成功提示；表新增/恢复在读 |
| 退选 | 行内「退选」 | `PUT /enrollment/{id}/drop` | status=已退选 |
| 恢复 | 行内「恢复」 | `POST /enrollment`（同学生+课程） | 恢复 status=1，**同一记录 id** |
| 重复有效选课 | 再对同一课「确定」 | `POST /enrollment` | 业务失败（前端 ElMessage 展示 message） |

- 后端：`enrollment` 路由全部 `require_roles("admin")`。  
- 清理：退选后可删临时选课行，或删临时学生（需先处理选课）。**勿动演示选课。**

### 3.6 资源管理（`/resource`）

| 操作 | 入口 | 接口 | 预期 |
|------|------|------|------|
| 列表/筛选 | 「教学资源」 | `GET /resource/list` | 分页列表 |
| 上传 | 「上传资源」→ 选课程与文件 →「开始上传」 | `POST /resource/upload` | 成功；列表可见 |
| 下载 | 「下载」 | `GET /resource/{id}/download`（Blob） | 浏览器下载；中文名靠 `Content-Disposition` filename* |
| 删除 | 「删除」 | `DELETE /resource/{id}` | 元数据删除；磁盘尽力清理 |

**类型白名单（后端）：** pdf, ppt, pptx, doc, docx, xls, xlsx, png, jpg, jpeg, mp4, mov。  
**大小：** 默认 50MB（`UPLOAD_MAX_BYTES`）。  
**内容校验：** 扩展名须与魔术字节/结构一致（如 TXT 改后缀 PDF 应 400）。

临时文件名建议 `__BA_res_xxx.pdf`（合法 PDF）；测完「删除」。

### 3.7 教师管理（`/teacher`，仅 Admin）

「新增教师」「编辑」「删除」「查看」；有关联课程时删除应失败（后端 409 类业务错误）。勿删演示「张老师」等。

## 4. Teacher 操作流程

**账号：** 登录页「教师」快捷填充。  
**身份（Seed 约定）：** 用户 `teacher` ↔ 教师档案「张老师」；本人课程含 *Vue3企业级开发*、*前端工程化实践*、*JavaScript进阶* 等（以库中 `teachers`/`courses` 为准，验收时对照列表 `teacherId`）。

| # | 检查项 | 前端表现 | 后端真实约束 |
|---|--------|----------|--------------|
| 1 | 菜单 | 无「教师管理」；课程标题为「我的课程」 | 路由 meta 过滤 |
| 2 | 本人课程 | `/course` 仅本人课 | `GET /course/list` 按 teacher 过滤 |
| 3 | 他人课程详情 | 打开他人课 URL | **403**「无权限访问」 |
| 4 | 本人学生 | `/student` 仅在读选课关联学生 | 列表 ACL；无关联则空 |
| 5 | 他人学生详情 | 直接拼 URL | **403** |
| 6 | 资源 | 可见本人课资源；可上传到本人课 | 跨课上传/下载 **403** |
| 7 | 选课 UI | 无「选课」按钮；详情无「选课管理」 | — |
| 8 | 选课 API | 浏览器控制台或 Swagger 调 `POST /enrollment` | **403**（admin-only） |
| 9 | 新增课程 | 无「新增课程」（无 `course:add`） | 即使调用也是 admin-only **403** |
| 10 | 新增/编辑学生 | **可能仍显示按钮**（Teacher 权限含 `student:edit`） | `POST/PUT /student` **admin-only → 403** |

验收重点：菜单隐藏 ≠ 安全；对 7–10 应用 Network 面板确认状态码。

临时资源可上传到张老师课程后删除；**不要**改演示教师 status（除非单独异常用例并恢复）。

## 5. 异常与权限测试

| # | 场景 | 操作方式 | 预期 HTTP | body 要点 | 前端 | 是否清登录 |
|---|------|----------|-----------|-----------|------|------------|
| 1 | 密码错误 | 登录错误密码 | 401 | message 登录失败类 | ElMessage 错误 | 否（本无会话） |
| 2 | 无效 Token | 改坏 `access_token` 后刷新/请求 | 401 | — | 清会话并跳转登录 | **是** |
| 3 | 教师停用旧 Token | Admin 将教师 status=0 后用旧 Token 访问 | 403 | `error=ACCOUNT_DISABLED` | 清会话跳转登录 | **是** |
| 4 | 普通 403 | Teacher 调 admin 接口或他人资源 | 403 | 一般无 ACCOUNT_DISABLED | ElMessage；**保留 Token** | **否** |
| 5 | 资源/课程不存在 | 访问极大 id | 404 | code=404 | 错误提示 | 否 |
| 6 | 重复选课 | Admin 对已在读课再分配 | 400 | 选课关系已存在类 | ElMessage | 否 |
| 7 | 有选课删课 | Admin 删有选课的课 | 409 | 无法删除类 | ElMessage | 否 |
| 8 | 非法扩展名 | 上传 `.exe` | 400 | 不支持的文件类型 | ElMessage | 否 |
| 9 | 伪造内容 | TXT 内容存为 `.pdf` | 400 | 内容与扩展名不符 | ElMessage | 否 |
| 10 | 超大文件 | 超过配置上限 | 400 | 文件过大 | ElMessage | 否 |

用例 3：测完必须把演示教师档案 **恢复 status=1**，否则影响后续演示。

## 6. 自动化 vs 浏览器

| 类别 | 自动化（`run_tests.py` 等） | 浏览器尚待 |
|------|---------------------------|------------|
| 登录/JWT/停用 ACCOUNT_DISABLED | 已有脚本 | 顶栏退出、刷新保活 |
| 课程/学生/资源 ACL、上传安全、选课 API | 已有脚本 | 真实点击、弹窗、下载文件打开 |
| Dashboard 卡片聚合 | 部分 | 图表布局、欢迎区日期/昵称 |
| 4.4.7 UI | typecheck/build | 视觉与交互人工看 |
